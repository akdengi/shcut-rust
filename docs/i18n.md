# Localization (i18n)

ShCut uses `@nuxtjs/i18n` for internationalization. Currently supports **English** and **Russian**.

## Adding a New Language

### 1. Create locale file

Copy `locales/en.json` to `locales/<code>.json` (e.g., `de.json` for German) and translate all values:

```bash
cp locales/en.json locales/de.json
# Edit locales/de.json — translate all string values, keep keys unchanged
```

**Important:** Escape `@` characters in values as `{'@'}` (vue-i18n treats `@` as a special linked-message character):

```json
// Wrong
"emailPlaceholder": "user@example.com"

// Correct
"emailPlaceholder": "user{'@'}example.com"
```

### 2. Register locale in nuxt.config.ts

Add the new locale to the `i18n.locales` array:

```ts
i18n: {
  locales: [
    { code: 'en', name: 'English', file: 'en.json' },
    { code: 'ru', name: 'Русский', file: 'ru.json' },
    { code: 'de', name: 'Deutsch', file: 'de.json' },  // ← add here
  ],
  // ...
}
```

### 3. Add language option to profile settings

In `pages/settings/profile.vue`, find the language selector options array and add the new locale:

```ts
const localeOptions = [
  { code: 'en', name: 'English' },
  { code: 'ru', name: 'Русский' },
  { code: 'de', name: 'Deutsch' },  // ← add here
]
```

### 4. Verify build

```bash
cd shcut-frontend-nuxt
npm run build
```

If the build passes, the new language is ready.

## Translation Keys Structure

All keys are organized by feature area:

| Key prefix | Area |
|------------|------|
| `common.*` | Shared labels (buttons, headings) |
| `shortcuts.*` | Shortcut list page |
| `auth.login.*` | Login page |
| `auth.signup.*` | Registration page |
| `auth.forgotPassword.*` | Forgot password page |
| `auth.resetPassword.*` | Reset password page |
| `settings.profile.*` | Profile settings |
| `settings.users.*` | User management |
| `settings.tags.*` | Tag management |
| `settings.workspace.*` | Workspace settings |
| `shortcutForm.*` | Create/edit shortcut form |
| `shortcutDetail.*` | Shortcut stats/detail page |
| `navigation.*` | Header navigation |

## How It Works

- **Templates:** Use `$t('key')` — e.g., `{{ $t('common.loading') }}`
- **Script setup:** Add `const { t } = useI18n()` and use `t('key')` — e.g., `success(t('shortcuts.toast.linkCopied'))`
- **Parameters:** Use `{name}` syntax — e.g., `$t('common.deleteConfirm', { name: item.name })`
- **Language selection:** Stored in cookie `shcut_i18n`, auto-detected from browser
- **Strategy:** `no_prefix` — language is not part of the URL, shared across all routes
